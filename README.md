# Big Data Bowl 2027

Team-specific scheme, roster and prospect modeling research.

1. [Team-indexed tendency pipeline](nfl-team-index/README.md): reusable NFL data views and explicit scheme-proxy inputs.
2. [Madden playbook matching](madden-matcher/README.md): evidence-aware route and partial-combination matching, constrained custom-book curation, reproducible batch exports and manual assembly sheets.

Source datasets, generated snapshots and credentials are kept outside this repository. Madden matches are explicit scheme proxies, not reconstructed NFL play calls or learned estimates of football value.
